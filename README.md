# guidy-releases

Sparkle update feed and release binaries for [Guidy](https://github.com/sabbivikas/guidy), a macOS app.

- `appcast.xml` - the Sparkle update feed the app polls.
- DMGs are attached to [GitHub Releases](../../releases).

This repo is public on purpose: the Sparkle updater in installed apps fetches the feed without authentication.
